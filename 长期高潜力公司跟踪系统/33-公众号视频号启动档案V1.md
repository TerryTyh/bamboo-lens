# 公众号视频号启动档案 V1

版本日期：2026-05-05

这份文档用于记录为什么要做个人公众号/视频号、应该怎么做、什么事情不能做，以及如何在后续运营中不忘记初心。

它不是一份营销方案，而是一份长期研究表达的启动档案。

## 一、初心

我们做这件事，不是为了追热点、喊买卖点、制造焦虑，也不是为了把研究系统包装成短期流量产品。

真正的出发点是：

1. 把长期高潜力公司跟踪系统中的研究成果，用更清楚、更克制、更容易传播的方式表达出来。
2. 通过公开写作和视频表达，倒逼自己持续研究、持续复盘、持续校准判断。
3. 为长期投资者提供一种可复核的公司分析方法，而不是提供简单答案。
4. 用时间序列建立信任：同一家公司持续跟踪，判断变化要有证据，估值变化要有假设。
5. 最终沉淀一个围绕公司质量、估值、风险和安全边际的个人研究品牌。

一句话初心：

> 用价值投资的方法，持续拆解好公司值多少钱、贵在哪里、便宜在哪里。

## 二、定位

### 1. 对外定位

面向长期投资者的公司估值与商业质量分析。

重点跟踪中国、美国和全球范围内具备长期研究价值的公司，关注商业模式、护城河、现金流、再投资空间、周期位置、估值区间和安全边际。

### 2. 不做什么

1. 不做荐股号。
2. 不追逐短期热点和情绪行情。
3. 不用夸张标题制造紧迫感。
4. 不承诺收益，不暗示确定性。
5. 不因为股价涨跌而倒推基本面结论。
6. 不为了更新频率而发布低质量内容。

### 3. 希望形成的用户心智

读者看到这个账号时，应该形成这样的印象：

- 这是一个长期跟踪公司的人。
- 这里的估值有假设、有区间、有边界。
- 观点不一定永远正确，但会解释为什么改变。
- 这里更关心商业质量和长期赔率，而不是短期涨跌。
- 这里的内容可以作为理解公司的参考，而不是买卖指令。

## 三、品牌气质

整体气质应当保持：

1. 克制。
2. 有数据。
3. 有判断。
4. 承认不确定性。
5. 说人话，不堆术语。
6. 偏机构研究，但不端着。
7. 重视长期跟踪，而不是单篇爆款。

可以优先考虑的名称方向：

- 竹鉴价值研究
- 竹鉴公司档案
- 竹鉴估值笔记
- 现金流研究所
- 安全边际笔记
- 长期价值备忘录

当前建议优先使用：

> 竹鉴价值研究

理由是它能承接现有的竹鉴研究系统，也有机会从个人内容号发展为长期研究品牌。

## 五、栏目设计

### 1. 公司深度

频率：每月 1-2 篇。

适合平台：公众号为主，视频号拆条传播。

固定结构：

1. 结论先行：现在怎么看？
2. 公司靠什么赚钱？
3. 过去几年经营质量如何？
4. 长期增长来自哪里？
5. 护城河是否真实？
6. 估值怎么做？
7. 当前价格隐含什么预期？
8. 最大风险是什么？
9. 后续继续跟踪什么指标？

### 2. 估值更新

频率：每周 1-2 家。

适合平台：视频号短视频 + 公众号短文。

固定结构：

1. 股价或估值发生了什么变化？
2. 基本面有没有同步变化？
3. 原有估值假设是否需要调整？
4. 当前价格隐含了什么预期？
5. 现在更像机会、合理、还是透支？

### 3. 财报速读

频率：财报季集中发布。

适合平台：视频号优先，公众号做汇总。

固定结构：

1. 这份财报最重要的 3 个变化。
2. 哪些变化强化了长期逻辑？
3. 哪些变化削弱了长期逻辑？
4. 管理层说了什么？
5. 估值假设是否需要调整？

### 4. 投资框架

频率：每两周 1 篇。

适合平台：公众号为主。

可选主题：

- 如何看自由现金流？
- ROIC 为什么重要？
- DCF 什么时候有用，什么时候危险？
- 周期股估值为什么不能只看低 PE？
- 平台公司的估值要看什么？
- 安全边际到底来自哪里？

### 5. 跟踪池月报

频率：每月一次。

适合平台：公众号为主，视频号做核心结论。

固定结构：

1. 本月观察池总览。
2. 本月最重要的五个变化。
3. 估值变得更有吸引力的公司。
4. 估值明显透支的公司。
5. 下月最值得继续跟踪的 3 个问题。

## 六、公众号与视频号分工

### 公众号

公众号承担信任和深度。

适合发布：

- 公司深度
- 估值模型解释
- 投资框架
- 跟踪池月报
- 财报系统复盘

公众号文章要做到：

1. 结论清楚。
2. 假设透明。
3. 风险明确。
4. 有时间序列感。
5. 方便半年后回看。

### 视频号

视频号承担触达和记忆点。

适合发布：

- 单家公司 2-5 分钟估值短评
- 一张图讲清商业模式
- 财报后 3 个关键变化
- 当前估值隐含什么预期
- 一家公司最大的误解是什么

视频形式早期不追求复杂制作，优先使用：

1. 口播 + 关键数据卡片。
2. 屏幕录制 + 图表讲解。
3. 人声讲解 + 估值表。

## 七、内容复用流程

一份研究内容，至少复用成三种形态：

1. 内部研究档案：沉淀在长期高潜力公司跟踪系统。
2. 公众号长文：面向读者讲清逻辑、估值和风险。
3. 视频号短视频：提炼一个最清楚的问题和结论。

推荐流程：

1. 先更新内部研究档案。
2. 再写公众号文章。
3. 从公众号文章拆出 3-5 条视频号脚本。
4. 每月把文章和视频反馈纳入复盘。

## 九、每周执行节奏

建议每周固定只做三件事：

1. 更新一条公司动态或估值观察。
2. 发布一篇公众号文章或短文。
3. 发布两条视频号短视频。

每周最低可接受版本：

- 1 篇公众号短文。
- 1 条视频号。
- 1 条内部跟踪记录。

如果某周没有足够高质量内容，宁可少发，不要凑发。

## 十、内容质量检查清单

每篇内容发布前，必须回答：

1. 这篇内容的核心问题是什么？
2. 结论是否在开头已经讲清楚？
3. 哪些是事实，哪些是推断，哪些是个人判断？
4. 估值假设是否明确？
5. 风险是否写得足够具体？
6. 是否避免了荐股语气？
7. 半年后回看，这篇内容是否仍然有参考价值？
8. 是否能拆成至少一条视频号短内容？

如果以上问题答不清楚，先不发布。

## 十一、合规与边界

每篇公众号文章和视频号简介中，都应保留类似表达：

> 本内容为个人研究记录，不构成投资建议。估值仅用于理解市场预期，核心假设可能随公司经营、行业环境和市场价格变化而调整。

表达中避免：

- 可以买
- 必涨
- 低估到离谱
- 目标价必到
- 错过就没有了
- 稳赚
- 抄底
- 赶紧上车

可以使用：

- 当前价格隐含的预期是
- 在某些假设下，合理估值区间可能是
- 更值得关注的是
- 需要继续验证
- 风险在于
- 这不构成买卖建议

## 十二、复盘机制

每月复盘一次，回答：

1. 哪些内容最能代表账号定位？
2. 哪些内容获得反馈，但偏离了长期定位？
3. 哪些公司值得继续深挖？
4. 哪些选题只是短期热闹？
5. 本月有没有因为流量诱惑降低研究标准？
6. 本月有没有把不确定的东西说得太确定？
7. 下个月最重要的 3 个研究问题是什么？

每季度复盘一次，回答：

1. 账号是否仍然服务于长期研究系统？
2. 是否形成了可积累的公司档案？
3. 是否有至少 3 家公司完成了多次连续跟踪？
4. 是否有判断被验证或证伪，并被公开修正？
5. 是否需要调整栏目节奏？

## 十三、不要忘记的提醒

1. 真正的壁垒不是第一篇文章多惊艳，而是半年后仍然能持续解释同一批公司。
2. 价值投资内容最稀缺的是可信的时间序列。
3. 公开表达不是为了显得永远正确，而是为了让判断接受复盘。
4. 估值不是算出一个数字，而是理解市场正在相信什么。
5. 不追热点不等于不关注变化，关键是只记录会改变长期逻辑的变化。
6. 账号的核心资产不是粉丝数，而是持续变厚的公司档案和研究信誉。
