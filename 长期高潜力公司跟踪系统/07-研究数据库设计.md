# 研究数据库设计 V1

这份设计不是技术实现文档，而是研究系统的数据骨架。无论你后续用 Notion、Airtable、Obsidian、Excel，还是做成自己的 App，都可以按这个结构搭。

## 一、核心对象

建议拆成四张主表：

1. `公司主表`
2. `事件主表`
3. `周期结论表`
4. `主题与行业表`

## 二、公司主表

一家公司只保留一条主记录，用来承接长期判断。

建议字段：

| 字段 | 含义 |
| --- | --- |
| company_id | 公司唯一 ID |
| company_name | 公司名称 |
| ticker | 股票代码 |
| market | 上市市场 |
| region | 主要经营区域 |
| industry | 一级行业 |
| sub_industry | 二级行业 |
| pool_level | A / B / C / 淘汰 |
| stage | 候选 / 初筛 / 正式跟踪 / 暂停 |
| one_line_thesis | 一句话逻辑 |
| moat_score | 护城河评分 |
| management_score | 管理层评分 |
| financial_score | 财务质量评分 |
| reinvestment_score | 再投资能力评分 |
| valuation_score | 估值吸引力评分 |
| total_score | 总分 |
| key_bull_case | 最强逻辑 |
| key_bear_case | 最大担忧 |
| next_checkpoints | 下一步验证点 |
| last_review_date | 最近复评日期 |
| next_review_date | 下次计划复评日期 |

## 三、事件主表

一切动态都进入这张表，再反哺公司主表。

建议字段：

| 字段 | 含义 |
| --- | --- |
| event_id | 事件唯一 ID |
| event_date | 事件日期 |
| company_id | 关联公司 |
| event_type | 财报 / 电话会 / 政策 / 行业 / 管理层 / 产品 / 资本运作 / 市场 |
| priority | P1 / P2 / P3 |
| title | 事件标题 |
| source_name | 来源名称 |
| source_link | 来源链接 |
| fact_summary | 事实摘要 |
| interpretation | 初步解读 |
| long_term_impact | 对长期逻辑的影响 |
| short_term_impact | 对短期经营的影响 |
| action_needed | 是否需要更新评级或结论 |
| created_at | 入库时间 |

## 四、周期结论表

这张表用于沉淀周报、月报、季报中的阶段性判断。

建议字段：

| 字段 | 含义 |
| --- | --- |
| review_id | 结论唯一 ID |
| review_period | 周 / 月 / 季 |
| review_date | 结论日期 |
| company_id | 关联公司 |
| previous_level | 原观察池分层 |
| new_level | 新观察池分层 |
| thesis_change | 核心逻辑是否变化 |
| valuation_change | 估值吸引力是否变化 |
| confidence_change | 研究确信度是否变化 |
| next_action | 下一步动作 |
| reviewer_notes | 备注 |

## 五、主题与行业表

用于管理自上而下的研究主题。

建议字段：

| 字段 | 含义 |
| --- | --- |
| theme_id | 主题唯一 ID |
| theme_name | 主题名称 |
| industry | 对应行业 |
| key_drivers | 核心驱动因素 |
| key_risks | 核心风险 |
| watch_metrics | 核心跟踪指标 |
| related_companies | 关联公司 |
| last_update_date | 最近更新日期 |

## 六、推荐关系

四张表建议这样关联：

- 公司主表是中心
- 事件主表多对一关联公司主表
- 周期结论表多对一关联公司主表
- 主题与行业表一对多关联公司主表

## 七、最低可运行版本

如果你现在想先轻量运行，不必一次建完整数据库。最低版本只需要：

1. 公司主表
2. 事件主表
3. 每周输出模板

这样就已经能开始发现、跟踪、复盘。

## 八、后续自动化方向

未来如果我们把它做成自动化系统，可以围绕这套数据骨架增加：

- 公司级新闻抓取
- 财报与电话会时间提醒
- 政策和行业变化监控
- 周报自动生成
- 观察池变化自动提示
