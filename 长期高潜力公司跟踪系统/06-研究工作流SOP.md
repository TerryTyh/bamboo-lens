# 研究工作流 SOP V1

这份 SOP 解决的是“信息很多，但怎么系统运转”的问题。目标是让候选公司发现、正式建档、动态跟踪和周期复盘形成闭环。

## 一、总流程

统一按下面五步走：

1. `发现`：识别潜在高质量公司，进入候选池。
2. `初筛`：用筛选规则判断是否值得正式跟踪。
3. `建档`：进入观察池后建立单公司档案。
4. `跟踪`：把高价值动态持续归档到公司与事件库。
5. `复盘`：按周、月、季调整分层与研究优先级。

## 二、发现阶段

目标：持续获得新的候选公司，但不陷入泛泛扫市场。

建议优先从四类来源找候选标的：

- 行业龙头与份额提升者
- 财务质量持续改善的公司
- 估值回落但长期逻辑未坏的优质公司
- 处于结构性成长行业中的关键公司

每个新标的只回答四个问题：

1. 它做什么？
2. 为什么现在值得关注？
3. 最强逻辑是什么？
4. 最大疑点是什么？

如果四个问题都答不出，就先不进入候选池。

## 三、初筛阶段

目标：快速判断值不值得花更多时间。

执行步骤：

1. 使用 [01-筛选规则.md](/Users/tianyuehua/Documents/项目/一个财务投资应用/长期高潜力公司跟踪系统/01-筛选规则.md) 打分
2. 查看是否触发一票否决项
3. 给出分层建议：A 候选、B 候选、C 候选或淘汰

建议时间预算：

- 普通候选公司：15-30 分钟
- 明显高潜力公司：30-60 分钟

初筛阶段不要陷入过度精细建模，先判断值不值得深看。

## 四、建档阶段

目标：把值得跟踪的公司沉淀成长期研究资产。

执行步骤：

1. 复制 [03-单公司研究模板.md](/Users/tianyuehua/Documents/项目/一个财务投资应用/长期高潜力公司跟踪系统/03-单公司研究模板.md)
2. 完成业务、行业、护城河、管理层、财务、估值、风险等核心栏位
3. 明确写出三件事：
   当前最强逻辑
   当前最大担忧
   下一步验证点

建档完成后，必须给出一个当前结论，不能只停留在“先看看”。

## 五、动态跟踪阶段

目标：把外部世界中真正有价值的变化收集进系统。

跟踪时遵守三个原则：

- 只记录与长期逻辑有关的事件
- 所有事件都要附来源和日期
- 所有事件都要判断对长期逻辑的影响方向

每次新增动态，建议统一流程如下：

1. 记录事件事实
2. 标注类别：公司 / 行业 / 政策 / 市场
3. 标注优先级：P1 / P2 / P3
4. 写一句“它改变了什么”
5. 判断是否需要修改公司结论或分层

## 六、每周工作节奏

每周建议固定完成四件事：

1. 新增 3-10 个候选标的线索
2. 深入建档 1-3 家最有价值的公司
3. 更新所有 A 池与 B 池公司的重大动态
4. 输出一份周报，更新分层与研究优先级

## 七、每月工作节奏

每月建议完成：

1. 系统复看 A 池与 B 池公司
2. 清理已经不符合策略的跟踪对象
3. 复盘过去一个月哪些判断被验证、哪些被证伪
4. 识别最值得投入下月精力的主题和公司

## 八、结论输出标准

每次输出结论都尽量固定成以下格式：

- `事实`：发生了什么
- `判断`：这件事的重要性如何
- `影响`：影响长期逻辑、短期经营还是只是市场噪音
- `动作`：继续跟踪 / 提升优先级 / 降级 / 淘汰

## 九、避免系统失真

这套系统最容易失真的地方有四个：

- 候选公司太多，真正建档太少
- 记录新闻太多，真正判断太少
- 太关注股价，忽略公司质量变化
- 模板写得很满，但没有持续更新

所以要始终坚持：

- 少而精地跟踪
- 事实和判断分开
- 动态必须反哺结论
- 结论必须能推动观察池调整
