# 长期高潜力公司跟踪系统 V1

这是一套面向长期投资者的研究操作系统，目标不是追逐短期热点，而是持续发现、筛选、跟踪并复盘值得长期共同成长的优秀公司。

## 系统目标

1. 定期发现潜在高质量公司，形成候选池。
2. 用统一标准筛选出值得长期跟踪的标的。
3. 用成熟框架分析公司质量、护城河、管理层、估值与风险。
4. 持续收集重要外部信息并归档到公司档案。
5. 将基本面变化与市场定价变化分开看，形成可执行结论。

## 观察池分层

- `A池：核心长期跟踪`
  业务模式优秀，长期空间大，已建立较高研究确信度。
- `B池：重点观察`
  有潜力，但关键变量仍需验证。
- `C池：主题观察`
  行业值得看，但公司质量、估值或管理层还不够清晰。
- `淘汰池：停止跟踪`
  逻辑破坏、治理恶化、估值与回报不匹配，或已不符合你的策略。

## 统一输出原则

- 所有结论必须区分“事实”“推断”“判断”。
- 所有重要变化必须写明日期、来源、影响方向。
- 不因为股价上涨就自动提高评级，不因为股价下跌就自动否定公司。
- 先判断公司变没变，再判断价格贵不贵。

3. 做成自动化流程，按周/月为你生成更新摘要与优先级调整建议。
