# 研究池改造执行清单 V1

版本日期：2026-04-26

## 要解决的问题

1. 研究池和真实决策场景有距离。
2. 一些动态只有标题和日期，内容太薄。
3. 没有原文链接的事件不该进入正式动态。
4. 日程类信息被写成判断，阅读价值低。
5. 日报容易为了“有内容”而凑内容。

## 立刻改

1. 首页改成“下一步工作台”，不放空泛说明。
2. 官方候选池保留标题和来源，但不生成判断。
3. 公司主页动态只保留真正读过原文、有摘要、有证据的事件。
4. 财报会、股东大会、电话会这类日程，放到“待验证日程”，不写估值影响。
5. 事件详情页补“原文链接、原文摘要、关键数字/表述、我的分析”。

## 先补哪些对象

1. 阿里：已有持仓相关性，也在研究池里，优先把云、AI、回购、估值修复讲清楚。
2. 立讯精密：已有持仓相关性，也在研究池里，优先补现金流、营运资本和财务质量。
3. 半导体 / AI / 机器人主题：先不急着建很多公司页，先做主题页，把 ETF 背后的产业逻辑讲清楚。
4. 其他真实组合里的公司：按风险和重要性逐步决定是否纳入研究池。

## 新动态最低标准

一条正式动态必须有：

1. 原文链接
2. 原文到底说了什么
3. 关键数字或关键表述
4. 这对公司业务意味着什么
5. 这对估值或动作意味着什么
6. 下一次该验证什么

不满足这些，就不要放进公司主页。

## 日报规则

1. 有正式研究事件才展开。
2. 没有实质变化就短报。
3. 候选线索不默认推送长篇。
4. 与当前重点研究对象相关的内容优先。
5. 不再用模板判断填充篇幅。

## 下一步

1. 清理现有公司主页里的浅动态。
2. 先重做阿里或立讯其中一家。
3. 事件详情页加原文链接字段。
4. 建一个“待验证日程”区域。
5. 再调整日报生成逻辑。
