# 信息源与采集策略 V1

长期跟踪最容易失败的地方，不是不会分析，而是信息采集失真。要么太杂，要么太慢，要么被低质量噪音淹没。这份策略的目标是让你只持续吸收真正影响长期价值的信息。

## 一、信息源优先级

所有信息源按可信度与价值，分成四层。

### S级：公司一手资料

这是最高优先级，必须长期跟踪。

- 年报、20-F、10-K、半年报、季报
- 年度股东信
- 财报电话会与业绩说明会
- 投资者日、资本市场日材料
- 官方新品发布、官网公告、新闻稿
- 并购、回购、分红、融资等正式公告

适用原因：

- 最接近原始事实
- 可直接观察管理层表述与口径变化
- 最适合沉淀长期判断

### A级：行业与监管一手资料

- 政府与监管机构公告
- 行业协会数据
- 海关、统计部门、能源、消费、地产等官方数据
- 海外准入和监管政策文件
- 产业链核心环节的正式公告

适用原因：

- 能帮助判断行业空间和制度约束
- 对政策驱动或监管敏感行业尤其关键

### B级：高质量二手研究

- 主流卖方研报
- 优秀长线投资人公开观点
- 高质量媒体深度报道
- 专业数据库与行业纪要

适用原因：

- 有助于快速补齐行业认知
- 能帮助发现市场共识与分歧

使用原则：

- 只作为辅助，不替代一手判断
- 二手资料只能帮助形成假设，不能直接当结论

### C级：低优先级信息

- 泛财经快讯
- 社交媒体观点
- 无来源传闻
- 日内股价异动解读

使用原则：

- 只用于发现线索，不用于做核心判断
- 如果没有一手或高质量来源验证，不进入正式结论

## 二、采集维度

每家公司建议固定采集以下七类信息：

1. `经营结果`
   财报、分业务表现、订单、利润率、现金流、资本开支。
2. `管理层表述`
   电话会问答、股东信、战略口径变化、风险提示变化。
3. `竞争格局`
   份额变化、竞品动作、行业整合、价格战与新品。
4. `行业景气`
   需求、价格、库存、供给、上下游变化。
5. `政策环境`
   监管、补贴、准入、关税、税收、区域政策。
6. `资本配置`
   分红、回购、并购、增发、债务结构、再投资方向。
7. `市场定价`
   估值区间、市场预期变化、股价偏离度。

## 三、采集频率建议

不同信息不需要同样频率。

### 每日或高频关注

- 收藏池公司重大公告
- 所属地区重要政策变化
- 行业重大突发事件
- 股价和估值异常波动

### 每周关注

- 行业关键数据
- 竞争对手主要动态
- 与核心公司相关的中观变化

### 每月关注

- 行业景气度汇总
- 估值区间复核
- 市场共识是否变化

### 每季必做

- 财报与电话会全量更新
- 公司评级与观察池重估
- 关键假设验证或修正

## 四、入库标准

并不是所有信息都值得写入系统。建议只有满足以下条件之一的信息才进入事件库：

- 影响公司长期竞争力
- 影响行业空间或竞争格局
- 影响管理层可信度
- 影响未来 1-3 年盈利或现金流判断
- 影响估值中枢或市场预期框架

如果只是“又涨了”“又跌了”“媒体很热”，一般不入库。

## 五、采集后的标准动作

每条重要信息进入系统后，都做四步：

1. `归类`
   公司 / 行业 / 政策 / 市场
2. `定级`
   P1 / P2 / P3
3. `解读`
   它改变了什么，没改变什么
4. `动作`
   更新公司档案 / 更新分层 / 只记录不调整

## 六、重点行业的额外采集项

有些行业要加看专属指标。

### 消费

- 价格带变化
- 渠道动销
- 复购率
- 品牌心智和新品反馈

### 科技与软件

- 产品迭代速度
- 客户留存与扩张
- 研发效率
- 平台生态与开发者活跃度

### 医药与医疗

- 管线推进
- 临床进展
- 审批与医保政策
- 核心产品生命周期

### 制造与工业

- 订单与产能利用率
- 单位成本变化
- 海外扩张与产能布局
- 行业供需变化

### 金融

- 资产质量
- 净息差或承保质量
- 资本充足率
- 监管约束变化

## 七、你和我后续的默认信息纪律

如果由我来持续做你的研究助理，我会默认遵守：

- 优先找一手来源
- 明确写出来源和日期
- 把事实、解读、判断拆开
- 不拿低质量快讯替代长期判断
- 遇到短期噪音时，先判断是否值得入库
