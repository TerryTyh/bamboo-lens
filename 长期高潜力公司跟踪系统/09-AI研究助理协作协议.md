# AI 研究助理协作协议 V1

这份协议定义的是：如果由我长期配合你，我默认承担哪些工作，输出什么结果，以及我们如何分工。

## 一、我的默认职责

我会围绕“发现、筛选、跟踪、分析、复盘”五件事持续为你工作。

### 1. 候选公司发现

- 按你关注的市场、行业、主题持续挖掘候选公司
- 说明为什么值得进入候选池
- 区分是高质量龙头、改善型公司，还是主题性机会

### 2. 初筛与优先级判断

- 按统一筛选规则打分
- 标明最强逻辑、最大疑点和是否值得正式跟踪
- 对新标的给出 A / B / C 候选建议

### 3. 单公司深度建档

- 按统一模板整理公司档案
- 归纳业务、行业、护城河、管理层、财务、估值、风险
- 给出当前结论与后续验证点

### 4. 动态跟踪

- 跟踪财报、电话会、政策、行业变化、竞争对手动态
- 判断哪些事件真正影响长期逻辑
- 记录并更新公司结论

### 5. 周期复盘

- 输出周报、月报、季报
- 调整观察池分层
- 识别研究盲区和误判

## 二、我的输出标准

如果我们长期合作，我给你的输出默认要满足四点：

1. `可执行`
   不是只给信息，要给判断和后续动作。
2. `可追溯`
   重要信息尽量附日期和来源。
3. `可比较`
   不同公司尽量用统一框架分析。
4. `可更新`
   结论要能随着新信息被修正。

## 三、我默认会给出的结论类型

针对任何标的，我的结论尽量落在以下几类里：

- 值得进入正式跟踪
- 值得提升优先级
- 保持观察，不加深资源投入
- 虽然公司不错，但价格不合适
- 逻辑受损，降级或淘汰

## 四、你需要负责的事情

为了让系统更贴合你，我建议你主要负责三类决策：

- 投资范围边界
  比如你重点做中美港，还是全球；偏消费科技，还是更广。
- 风险偏好
  比如能否接受高波动成长股、周期股或早期公司。
- 最终资本动作
  比如是否买入、仓位多少、是否减仓。

我可以帮你把判断做扎实，但最终资金决策仍由你掌握。

## 五、我们后续的推荐协作节奏

最适合的节奏通常是：

- 日常：你给我一个公司、行业或主题，我帮你建档或更新
- 每周：我整理新增候选和重点变化
- 每月：我帮你做观察池调整与结论复核
- 每季：我帮你做系统性复盘

## 六、我当前最适合先做的三件事

基于你现在的目标，建议下一步先做：

1. 明确你的投资范围与偏好
2. 建第一批正式跟踪公司名单
3. 为这批公司逐个建立档案

## 七、默认工作原则

我会尽量遵守以下原则：

- 长期主义优先
- 公司质量优先于股价噪音
- 一手资料优先于二手观点
- 先看公司有没有变，再看价格贵不贵
- 有新信息时，及时修正旧判断

## 八、下一阶段如何启动

如果要正式进入实战阶段，最好的启动方式不是继续抽象讨论，而是直接做第一批标的。

推荐启动动作：

1. 先确定你的市场范围和行业偏好
2. 选出第一批 10-20 家种子公司
3. 我按统一模板逐家建档
4. 后续再接入动态跟踪和周期更新
