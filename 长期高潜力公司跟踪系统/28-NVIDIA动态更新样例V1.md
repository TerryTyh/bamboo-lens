# NVIDIA 动态更新样例 V1

版本日期：2026-04-12

说明：

- 这是第八份“真实动态更新样例”。
- 目标是展示：对 AI 基础设施平台公司，动态跟踪的重点不在“新品多不多”，而在“训练到推理的需求扩张、平台化能力和大客户资本开支能否继续形成正反馈”。

## 一、本次更新结论

- 当前结论：`维持 A 池核心`
- 结论变化：`长期逻辑继续强化，并适度提升研究优先级`
- 原因：
  最近几次官方披露已经非常清楚，NVIDIA 的核心逻辑早已不是单一 GPU 周期，而是以数据中心、网络、软件和整机平台共同构成的 AI 工厂底座。当前真正要盯的，不是“还有没有高增长”，而是“推理需求、平台化能力和全球大客户资本开支能否继续互相强化”。

## 二、本次纳入系统的 5 条动态

### 动态 1：FY26 Q4 与全年业绩再创新高，数据中心业务继续主导增长

- 日期：2026-02-25
- 事件类型：财报
- 事实：
  公司披露 FY26 Q4 收入 681.27 亿美元，同比增长 73%，其中数据中心收入 623.14 亿美元，同比增长 75%；FY26 全年收入 2,159.38 亿美元，同比增长 65%，数据中心全年收入 1,937.37 亿美元，同比增长 68%。
- 判断：
  这是 `P1` 级别的强化信息。它说明 NVIDIA 仍然处在 AI 基础设施主线最中心的位置，而且增长并没有因为高基数而明显失速。
- 动作：
  `维持原判断`
- 优先级：
  `P1`

### 动态 2：FY27 Q1 指引继续上修到 780 亿美元，但公司明确不假设来自中国的数据中心计算收入

- 日期：2026-02-25
- 事件类型：财报指引
- 事实：
  公司给出 FY27 Q1 收入指引 780 亿美元，上下浮动 2%；同时明确表示，这一指引不包含来自中国的数据中心计算收入。Q1 GAAP 和 non-GAAP 毛利率指引分别为 74.9% 和 75.0%。
- 判断：
  这条信息非常关键，因为它说明即使在相对保守的地缘假设下，公司仍然给出非常强的增长与盈利能力指引。
- 动作：
  `提升优先级`
- 优先级：
  `P1`

### 动态 3：Meta 扩大与 NVIDIA 的多代际合作，进一步验证超大客户资本开支强度

- 日期：2026-02-17
- 事件类型：客户 / 合作
- 事实：
  公司宣布与 Meta 建立多年度、多代际战略合作，覆盖本地部署、云和 AI 基础设施，涉及大规模部署 NVIDIA CPU、网络产品以及数以百万计的 Blackwell 和 Rubin GPU。
- 判断：
  这是 `P1` 级别的信息。它强化了一个关键结论：NVIDIA 的增长不只是短期订单高景气，而是被头部平台客户写进了多年资本开支路线图。
- 动作：
  `提升优先级`
- 优先级：
  `P1`

### 动态 4：Rubin 平台、NVLink Fusion 和光互连合作，说明公司正在继续向更完整的 AI 工厂平台扩张

- 日期：2026-01-05 / 2026-03-02 / 2026-03-16 / 2026-03-31
- 事件类型：产品 / 平台 / 供应链
- 事实：
  公司在 CES 和 GTC 期间连续披露 Rubin 平台、Vera Rubin 全生产、NVLink Fusion，以及与 Lumentum、Coherent、Marvell 的合作与投资安排，持续强化光互连、网络与半定制基础设施布局。
- 判断：
  这是一条 `P1` 级别的信息。它说明 NVIDIA 正在从“最强 AI 芯片公司”继续演进为“AI 工厂平台公司”，未来护城河越来越依赖系统级协同，而不是单点芯片领先。
- 动作：
  `维持原判断`
- 优先级：
  `P1`

### 动态 5：高增长继续，但毛利率、库存与客户集中度仍然需要持续验证

- 日期：2025-11-19 / 2026-02-25
- 事件类型：财报 / 风险跟踪
- 事实：
  FY26 Q3 收入 570.06 亿美元，同比增长 62%，Q4 继续升至 681.27 亿美元；但随着平台化扩张，公司也在继续大规模投入，且业务高度集中于数据中心与少数超大客户。Q3 末库存 197.84 亿美元，较年初大幅提升。
- 判断：
  这是一条 `P2` 级别的提醒信息。长期逻辑没有被削弱，但后续必须把毛利率、库存变化和超大客户 capex 波动一起看，而不能只看收入。
- 动作：
  `需要二次验证`
- 优先级：
  `P2`

## 三、这次更新后，我对 NVIDIA 的最新判断

### 1. 改变了什么

- 过去更容易把 NVIDIA 理解成“AI GPU 龙头”。
- 这次更新后，更准确的理解应该是：
  `数据中心芯片 + 网络 + 软件 + AI 工厂平台`
  共同构成的基础设施平台公司。

### 2. 没改变什么

- 它仍然是一家高度依赖超大客户资本开支和技术迭代节奏的公司。
- 业务高度集中于数据中心，意味着市场对需求变化会非常敏感。
- 对它的跟踪，仍然不能只看产品发布，而要看客户 capex、平台采用深度和毛利率质量。

### 3. 当前最强逻辑

- AI 从训练走向推理、从模型走向 AI 工厂，正在持续放大 NVIDIA 的平台价值，而不是削弱它。

### 4. 当前最大担忧

- 一旦超大客户资本开支节奏放缓、半定制芯片加速替代，或平台化扩张压缩盈利质量，市场预期可能会快速收缩。

## 四、接下来最值得盯的 5 个点

1. 下一次 FY27 Q1 财报里数据中心收入和毛利率
2. 推理需求是否继续接棒训练需求，成为更稳定的增长来源
3. 超大客户资本开支是否继续维持高位
4. NVLink、网络和光互连是否继续强化平台护城河
5. 库存、应收和资本开支链条是否出现过热迹象

## 六、这次实践的意义

通过 NVIDIA 这次更新，你可以看到：

- 对 AI 基础设施平台公司，关键不是“有没有新芯片”，而是平台是否继续扩张
- 对这类公司，研究重点必须把产品、客户 capex、网络 / 光互连和盈利质量放在一起看
- 这和微软的平台现金流逻辑、TSMC 的制造底座逻辑、GE Vernova / Constellation 的电力逻辑都不同

- 研究动作：`维持 A 池核心，并适度提升研究优先级`
