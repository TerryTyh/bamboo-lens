# 手机友好简报格式 V1

版本日期：2026-04-11

目标：

- 适合手机端快速阅读
- 适合电脑端扫读
- 不让信息过载

## 一、日简报格式

每份日简报只保留 4 个部分。

### 1. 今日一句话

用一句话先说清楚今天最重要的判断。

示例：

- 今天没有公司逻辑被推翻，但阿里巴巴和立讯精密各出现一条值得跟踪的质量信号。

### 2. 今日关键变化

最多 3 条，每条固定写成：

- 公司：
- 事实：
- 判断：
- 动作：

### 3. 今日无需动作

列出哪些变化只是记录，不需要你调整看法。

### 4. 决策提示

固定只写 3 行：

- 研究动作：
- 资金动作建议：
- 下一次验证点：

### 5. 明日重点

只写明天最值得看的 1-2 件事。

## 二、周报格式

每份周报只保留 5 个部分。

### 1. 本周一句话结论

示例：

- 本周核心跟踪池长期逻辑整体稳定，但制造链公司要提高对现金流质量的关注。

### 2. 本周 5 条关键变化

每条固定写成：

- 公司：
- 事实：
- 判断：
- 动作：
- 优先级：

### 3. 观察池状态表

| 公司 | 当前状态 | 本周判断 | 当前动作 |
| --- | --- | --- | --- |
|  |  |  |  |

### 4. 本周没有改变的事情

这一部分专门防止被噪音带偏。

### 5. 决策提示

这一部分固定写：

- 本周最值得提高研究优先级的公司：
- 本周最该暂停动作的公司：
- 本周最值得等待验证的信号：

### 6. 下周最该盯的 3 件事

只写最重要的 3 条。

## 三、所有简报统一动作词

以后所有简报里的动作，统一只用这 5 个：

- `提升优先级`
- `维持原判断`
- `需要二次验证`
- `下调确信度`
- `降级出池`

## 四、所有简报统一阅读原则

- 先看一句话结论
- 再看关键变化
- 最后只看决策提示

你平时不需要先打开完整档案。
只有当某家公司连续出现重要变化时，再回到完整版档案深看。

## 五、决策提示的默认写法

以后所有简报里的决策提示，统一尽量写成：

- 研究动作：维持原判断 / 提升优先级 / 需要二次验证 / 下调确信度 / 降级出池
- 资金动作建议：继续观察 / 进入分批加仓候选 / 暂停加仓 / 适度降仓 / 逐步退出
- 下一次验证点：只写一个最关键的观察点
