# 八家核心公司首次跟踪任务清单 V1

版本日期：2026-04-11

这份清单解决的是：研究档案建好了，下一步具体该盯什么。

原则：

- 每家公司先抓 5 个最值得跟的事件
- 再抓 3 个最重要的长期信号
- 不追求面面俱到，先抓最有信息含量的部分

## 门户优化备忘

1. 公司主页后续补充“财务分析板块”
2. 财务分析板块建议固定覆盖：
   - 收入结构与增长质量
   - 利润率与现金流
   - 资本开支与资本回报
   - 当前估值观察点
3. 三级事件页后续补充“原始网页链接”
   - 优先放官方公告、财报页、电话会或新闻原文
   - 不再提供仅回跳到内部摘要 Markdown 的链接
4. 公司主页后续补“财务数据列表 + 估值方法”
   - 至少补近 3-5 年关键财务数据
   - 明确估值口径、当前估值水平和判断依据
   - 在没有真实数据与方法前，页面不展示空壳“财务与估值”板块
5. 公司主页的“怎么继续跟踪”要继续增强
   - 每条跟踪项都要写清楚去哪里看
   - 尽量减少抽象表述，改成可执行检查项
6. 云端版简报系统迁移
   - 把日简报/周报从本地自动化迁到云端执行
   - 优先采用 `GitHub Actions + PushDeer / 企业微信 + 当前研究门户`
   - 第一步先跑通“稳定的日报推送”，再做门户联动
