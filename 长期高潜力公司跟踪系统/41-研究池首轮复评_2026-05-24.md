# 研究池首轮复评

复评日期：2026-05-24

本次复评是研究池生命周期 V1 建立后的第一次最小复评。它不试图重做每家公司完整估值，只回答三个问题：当前层级是否仍成立，是否需要升级/降级/移出，下次复评最该验证什么。

## 一、总结果

| 项目 | 结论 |
| --- | --- |
| A 层核心 | 8 家维持 |
| B 层重点观察 | 1 家维持，长电科技仍为强 B |
| 本轮升级 | 无 |
| 本轮降级 | 无 |
| 本轮移出 | 无 |
| 下次复评 | 2026-06 |

本轮不调整层级。原因是：A 层公司仍各自具备明确长期主线、可跟踪信息源和公司页沉淀基础；长电科技已完成最小研究包，但关键验证点还不足以支撑建正式主页。当前更重要的是把月度复评节奏跑稳，而不是为了动作感强行升降级。

## 三、本轮不调整层级的原因

1. 没有公司出现足以触发 A → B 的连续负面证据。
2. 没有 B 层公司完成 B → A 的关键验证。
3. 多数风险属于“下次财报/经营数据必须验证”，而不是“当前层级已经失效”。
4. 研究池刚建立，首轮复评更应该校准节奏和验证点，而不是制造层级波动。

## 四、下次复评动作

1. 2026-06 对 8 家 A 层逐一确认：维持、A 层重点复核、降级观察或移出。
2. 对长电科技只看四个硬点：先进封装收入含金量、长电微亏损、毛利率、经营现金流。
3. 对阿里巴巴、汇川技术、立讯精密设置更高财务质量权重，避免公司页只讲长期故事。
4. 对 NVIDIA、GE Vernova、Constellation Energy 设置估值容错率检查，避免主题强但价格过度预支。
