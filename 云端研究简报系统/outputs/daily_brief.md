# 竹鉴日报 | 2026-05-27

今日关键变化：

1. 公司：NVIDIA
   事件：FY2027 Q1：收入 US$81.6b、数据中心 US$75.2b，Q2 指引 US$91.0b，AI 工厂平台逻辑继续强化
   核心内容：2026-05-20，NVIDIA 公布 FY2027 Q1 财报：季度收入 816.1 亿美元，环比增长 20%，同比增长 85%；数据中心收入 752 亿美元，环比增长 21%，同比增长 92%；数据中心计算收入 604 亿美元，同比 +77%，环比 +18%；数据中心网络收入 148 亿美元，同比 +199%，环比 +35%；GAAP / non-GAAP 毛利率分别为 74.9% / 75.0%；GAAP 稀释 EPS 为 US$2.39，non-GAAP 稀释 EPS 为 US$1.87；自由现金流 485.5 亿美元。公司给出 FY2027 Q2 收入指引 910 亿美元，上下浮动 2%，且不假设来自中国的数据中心计算收入。公司还新增 800 亿美元 股票回购授权，并将季度分红从 US$0.01 提高到 US$0.25。
   关键证据：2026-05-20，NVIDIA 公布 FY2027 Q1 财报：季度收入 816.1 亿美元，环比增长 20%，同比增长 85%；数据中心收入 752 亿美元，环比增长 21%，同比增长 92%；数据中心计算收入 604 亿美元，同比 +77%，环比 +18%
   为什么重要：这是 P1 级财报与指引强化事件。NVIDIA 不只是继续高增长，而是在高基数下同时兑现数据中心增长、约 75% 毛利率、强自由现金流和更高 Q2 指引。数据中心网络收入同比 +199%、环比 +35%，尤其值得重视：它说明 NVIDIA 的 AI 工厂平台逻辑正在从 GPU 计算扩展到网络、互连和系统级协同。Q2 指引不假设中国数据中心计算收入仍达到 910 亿美元，也强化了全球 AI 基础设施需求的广度。
