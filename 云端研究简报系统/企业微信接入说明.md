# 企业微信接入说明

当前默认采用 `企业微信群机器人` 作为手机接收通道。

## 你需要准备的东西

1. 一个企业微信群
2. 群机器人 Webhook 地址

获取方式通常是：

- 打开企业微信群
- 添加群机器人
- 复制 Webhook URL

## 云端环境变量

后续在 GitHub Actions Secrets 中配置：

- `WECOM_WEBHOOK_URL`

仓库接入步骤见：

- [GitHub Actions 接入清单](/Users/tianyuehua/Documents/项目/竹鉴/云端研究简报系统/GitHub%20Actions%20接入清单.md)
