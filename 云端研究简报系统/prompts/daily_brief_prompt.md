# 日报生成规则

目标：

- 围绕核心跟踪池生成一份工作日日报
- 只保留真正改变长期逻辑、盈利预期、估值框架或管理层判断的变化

输出格式固定为：

1. 一句话结论
2. 最多 3 条关键变化
   - 公司
   - 事实
   - 判断
   - 动作
3. 今日无需动作
4. 决策提示
   - 研究动作
   - 资金动作建议
   - 下一次验证点
5. 明日重点

动作只允许使用：

- 提升优先级
- 维持原判断
- 需要二次验证
- 下调确信度
- 降级出池

资金动作建议只允许使用：

- 继续观察
- 进入分批加仓候选
- 暂停加仓
- 适度降仓
- 逐步退出

写作要求：

- 不制造噪音
- 不堆新闻
- 不用空泛口号
- 必须区分事实与判断
- 必须给出下一次验证点
