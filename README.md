# Bamboo Lens / 竹鉴

`竹鉴（Bamboo Lens）` 是一个面向长期投资研究的智能门户系统。

当前仓库包含三层内容：

- `长期高潜力公司跟踪系统/`
  研究框架、公司档案、动态样例、实施规划
- `研究门户/`
  本地可阅读的研究门户原型
- `云端研究简报系统/`
  工作日日报、企业微信推送、GitHub Actions 云端执行骨架

当前阶段目标：

1. 先跑通稳定的云端日报
2. 再把动态事件沉淀回研究门户
3. 最终形成一个会持续积累、持续学习、持续完善框架的投资研究系统

## 周末同步入口

双击根目录的 `同步并启动竹鉴.command`，它会：

1. 从 GitHub 拉取云端日报、事件库和候选池的最新回写。
2. 生成 `云端研究简报系统/outputs/weekend_sync_summary.md`。
3. 启动本地研究门户并打开首页估值决策总览。

这一步是动态决策系统的本地入口：工作日看企业微信日报，周末用它把云端沉淀同步回门户做系统复盘。
