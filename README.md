# 竹鉴 / Bamboo Lens

竹鉴是一个持续积累公司研究、正式事件、估值判断和投资动作的长期投资研究系统。

## 目录结构

| 目录 | 用途 | 主要入口 |
| --- | --- | --- |
| `研究门户/` | 本地与 GitHub Pages 研究界面 | `研究门户/index.html` |
| `云端研究简报系统/` | 候选采集、正式事件、日报、企业微信和自动化脚本 | `云端研究简报系统/README.md` |
| `长期高潜力公司跟踪系统/` | 研究规则、历史档案和方法论知识库 | `长期高潜力公司跟踪系统/00-从这里开始.md` |
| `docs/产品设计/` | 产品 PRD 与交互设计 | 三份 MVP 文档 |
| `资料/公司财报/` | 公司原始财报 | 按公司归档 |
| `资料/资产快照/` | 个人组合截图等私有输入 | 按日期逐步归档 |
| `.github/workflows/` | GitHub Actions 自动化 | 候选采集、日报、事件提升、门户部署 |
| `.codex/` | Codex 项目索引和交接说明 | `.codex/PROJECT.md` |

根目录只保留项目导航、协作规则、启动器和工程配置。新增内容应进入上表对应目录，不再散落在根目录。

## 快速开始

1. 双击 `同步并启动竹鉴.command`：同步远端、刷新研究数据并启动本地门户。
2. 或在项目根目录运行 `python3 -m http.server 8765`，打开 `http://127.0.0.1:8765/研究门户/index.html`。
3. 处理候选线索时进入 `研究门户/candidates.html`。

## 研究质量门槛

- 首页“最近更新”和日报关键变化只展示完成原文研判的正式事件。
- 标题、日程、公告列表页和营销文案只能留在候选池。
- 正式事件必须包含来源、正文摘要、至少三条证据、业务影响、估值或动作影响、下一步验证点。
- 没有估值模型时不虚构买入价或卖出价。

## Codex 协作

Codex 会话进入本项目后先阅读：

1. `AGENTS.md`
2. `.codex/PROJECT.md`
3. `研究门户/docs/research/竹鉴推进状态与下一步.md`
4. 最新一份 `研究门户/docs/research/*周总结*` 文档

全局固定入口：`~/.codex/projects/竹鉴`。
