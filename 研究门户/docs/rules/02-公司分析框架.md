# 公司分析框架 V1

这套框架融合了长期复利投资、质量成长投资和价值投资的一些核心思想，重点不是做宏大叙事，而是判断“一家公司是否值得长期持有式跟踪”。

## 1. 业务理解

必须先回答清楚：

- 公司具体卖什么？
- 它的客户是谁？
- 客户为什么购买？
- 公司如何赚钱？
- 收入拆分如何？
- 哪些业务是核心引擎，哪些只是辅助？

如果你无法用 3 分钟解释清楚这家公司，就不要急着研究估值。

## 2. 行业空间

关键问题：

- 行业当前处于导入期、成长期、成熟期还是衰退期？
- 行业空间来自渗透率提升、消费升级、替代逻辑，还是全球化扩张？
- 行业增长是周期性还是结构性？

重点看：

- 长期需求是否稳定扩张。
- 行业是否允许龙头形成规模优势。
- 未来 5-10 年是否还有份额集中机会。

## 3. 护城河

可以从以下五类护城河里判断：

- 品牌与用户心智
- 网络效应
- 规模成本优势
- 切换成本
- 无形资产或技术平台

重点不是“有没有优势”，而是：

- 优势是否能量化
- 优势是否能持续
- 优势是否在增强

## 4. 管理层

观察四件事：

- 诚信
- 能力
- 激励机制
- 资本配置

常用判断问题：

- 管理层是否正视问题，还是回避问题？
- 历史承诺兑现情况如何？
- 遇到逆风时，是继续投入主航道，还是频繁换故事？
- 并购、回购、分红和融资是否为股东创造价值？

## 5. 财务质量

至少要看这几类指标：

- 收入增长与增长质量
- 毛利率、营业利润率、净利率
- ROE、ROIC
- 自由现金流
- 资产负债表强度
- 营运资本效率

观察重点：

- 利润是否可持续
- 现金是否真实回流
- 高回报率是否具备可持续性
- 增长是否以牺牲资产质量为代价

## 6. 再投资能力

长期大牛股通常不是“只会赚钱”，而是“会持续把钱投向高回报项目”。

要判断：

- 公司未来还有哪些再投资机会？
- 核心业务是否还有扩张空间？
- 新业务是否基于已有能力外溢，而不是盲目跨界？
- 每增加一单位资本，能否产生可观回报？

## 7. 风险框架

把风险拆成五类：

- 行业风险：需求下降、政策限制、技术替代
- 竞争风险：份额流失、价格战、产品落后
- 治理风险：关联交易、激励扭曲、财务可信度
- 财务风险：高杠杆、再融资依赖、现金流脆弱
- 估值风险：市场预期过高、估值透支未来

关键不是列风险，而是判断：

- 风险发生的概率
- 一旦发生的损害程度
- 公司是否有应对能力

## 8. 估值框架

估值不追求“精确到小数点”，重点在于判断：

- 市场当前在定价什么？
- 价格对应的假设是否过于乐观或悲观？
- 未来回报更多来自盈利增长，还是估值变化？

建议同时用三层估值视角：

- `相对估值`：PE、PB、EV/EBIT、EV/FCF 与自身历史、同行对比
- `经营估值`：根据收入、利润、现金流增长假设，推演未来几年合理区间
- `资产价值`：适合金融、地产、资源、周期类公司，重点看净资产和重估逻辑

## 9. 决策结论

分析的目标不是写报告，而是输出明确结论。建议结论固定为以下五类之一：

- `进入 A 池`
- `进入 B 池`
- `进入 C 池`
- `继续观察，不建立正式跟踪`
- `淘汰`

每个结论都要配三句话：

- 当前最强逻辑是什么
- 当前最大担忧是什么
- 下一步最该验证什么
