# 新增公司准入标准 V1

这份标准用于以后评估你新推给我的公司：它是否值得进入竹鉴研究池，应该进入哪一层，以及入池前必须先补哪些信息。

核心原则很简单：不是因为“听起来热门”就加入，而是因为它有机会在多年维度持续创造价值，并且我们有能力跟踪它。

## 一、先判定是否值得花研究资源

一家公司要进入竹鉴，至少需要满足下面 4 个基础条件。

### 1. 能用一句话讲清楚它靠什么赚钱

必须能回答：

- 它卖什么产品或服务？
- 谁是客户？
- 客户为什么愿意持续付钱？
- 这门生意未来是否可能变得更大、更强或更赚钱？

如果一句话讲不清，先不入池，只放到待理解清单。

### 2. 所属主线足够重要

优先考虑这些长期主线：

- AI 算力、云、企业软件和数字化基础设施。
- 先进制造、半导体、电气化、工业自动化。
- 稳定能源、电网、核电、数据中心供电。
- 高质量平台现金流、消费基础设施和全球供应链。
- 你真实持仓或重点关注公司相关的上下游、竞品和替代品。

如果公司只是短期热点，没有长期主线支撑，不进入正式研究池。

### 3. 有可跟踪的公开信息源

至少要能拿到下面一种信息：

- 年报、季报、业绩会、投资者日、公告。
- 官方新闻稿、投资者关系页面、监管披露。
- 可靠行业数据或核心客户、竞品、供应链线索。

如果没有稳定信息源，系统无法持续跟踪，最多进入观察清单。

### 4. 它可能影响你的真实决策

优先级更高的公司通常满足其中之一：

- 你已经持有，或可能在未来 6-24 个月考虑买入。
- 它和现有核心池公司强相关，能帮助理解产业链。
- 它代表一个重要长期变量，比如能源安全、AI 基础设施、制造升级。
- 它能作为对照公司，帮助判断已有公司的估值和竞争力。

如果完全不影响决策，也和长期主题无关，就不占用研究池名额。

## 二、一票暂缓项

出现下面情况时，即使公司很热门，也先不进入正式研究池。

- 商业模式暂时看不懂，无法解释收入和利润来源。
- 财务质量明显异常，利润和现金流长期严重背离且无合理解释。
- 治理、诚信、关联交易或信息披露有明显疑点。
- 负债结构脆弱，短期偿债、再融资或流动性风险过高。
- 估值完全依赖激进叙事，缺少收入、利润、现金流或资产支撑。
- 缺少稳定信息源，无法持续跟踪。
- 只因股价上涨、社媒热度或概念炒作而被关注。

暂缓不是永久否定，而是先不投入系统性研究资源。

## 三、入池分层

### A 层：核心跟踪候选

适合进入公司主页和长期动态跟踪。

标准：

- 长期主线明确。
- 商业模式可理解。
- 公司具备较强竞争优势或稀缺资产。
- 财务数据有足够可读性。
- 估值可以被拆解，不只是讲故事。
- 对真实决策或核心研究池有重要影响。

输出要求：

- 建公司主页。
- 建立业务地图、财务地图、估值框架。
- 接入官方来源和动态事件。
- 每次重大事件都要判断是否回写主页。

### B 层：重点观察候选

适合先观察，不急着写完整公司主页。

标准：

- 所属主线重要，但公司质量、估值或信息源还没完全确认。
- 有一两个关键问题待验证。
- 可能成为未来 A 层，但现在证据不足。

输出要求：

- 建一页式观察卡。
- 明确 3-5 个验证点。
- 只在重大财报、重大公告或行业变化时更新。

### C 层：轻量雷达

适合放在雷达里，不做持续研究。

标准：

- 有一定关注价值，但目前离投资决策较远。
- 主要用于行业对照、竞品观察或未来备选。

输出要求：

- 只记录公司名称、主线、为什么关注、下一次触发条件。
- 不进入日报重点，不占用公司主页资源。

### 暂不入池

适合先放下。

标准：

- 看不懂、不可跟踪、不可估值，或离真实决策太远。
- 只有情绪、概念或短期涨跌驱动。

输出要求：

- 给出暂不入池原因。
- 如果有必要，列出未来重新评估条件。

## 五、入池后第一步做什么

如果评估为 A 层或强 B 层，下一步不是立刻写长篇档案，而是先完成最小研究包：

1. 公司一句话逻辑。
2. 业务结构和主要客户。
3. 最近一份财报或年报的关键数字。
4. 当前市场估值和合理估值粗框架。
5. 未来 3 个最重要验证点。
6. 官方信息源和后续自动跟踪入口。

只有最小研究包完成后，才正式进入公司主页。

## 六、和既有核心池的关系

新增公司不能无限扩张。每加入一家公司，都要说明它补的是哪块拼图：

- 补行业主线：帮助理解一个新的长期变量。
- 补产业链：帮助理解已有核心公司的上下游。
- 补竞品对照：帮助判断已有公司的护城河和估值。
- 补真实决策：与你持仓、计划买入或重点观察直接相关。

如果说不清它补哪块拼图，就先不加入正式研究池。
