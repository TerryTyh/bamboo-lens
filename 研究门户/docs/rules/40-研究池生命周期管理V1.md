# 研究池生命周期管理 V1

版本日期：2026-05-23

这份规则解决一个核心问题：竹鉴不能只整理已经看过的公司，而要持续发现新公司，并且定期复评旧公司。A 层不是终身制，B 层也不是冷宫；公司必须随着事实、财务、估值和信息源质量变化而升级、降级或移出。

## 一、研究池的四层状态

| 层级 | 定义 | 系统动作 |
| --- | --- | --- |
| A 层核心 | 已有清晰长期逻辑、可跟踪信息源、财务与估值框架，能影响真实决策 | 建公司主页，接入动态回写，重大事件必须沉淀 |
| B 层重点观察 | 方向重要，但仍有关键变量未验证 | 建一页式研究卡和最小研究包，只跟踪重大事件 |
| C 层轻量雷达 | 有参考价值，但暂不值得系统投入 | 只保留名称、主线、关注理由和触发条件 |
| 暂不入池 | 看不懂、不可跟踪、不可估值，或离决策太远 | 给出暂缓原因和重新评估条件 |

## 二、自主发现候选公司的来源

每周从下面六类长期主线中寻找 3-10 个新候选线索：

1. AI、云、企业软件和数字化基础设施。
2. 半导体、先进封装、先进制程和关键设备材料。
3. 先进制造、工业自动化、全球供应链和复杂制造平台。
4. 稳定能源、电网、核电、燃气、电力设备和数据中心供电。
5. 高质量平台现金流、消费基础设施和全球化品牌。
6. 现有核心公司的上下游、竞品、替代品和关键客户。

自主发现只负责“进入候选”，不直接升 A。任何新公司必须先过准入标准和最小研究包。

候选发现还必须保持中企和外资结构均衡。原则上，每周新增候选中，中企（A 股、港股、中概、国内产业链公司）不少于一半；如果某周外资事件明显更多，也要至少补 2-3 条中企候选或说明为什么没有合格来源。NVIDIA、TSMC、Microsoft 等外资核心公司只在出现硬事件时提高优先级，不能因为英文信息源更顺手而长期挤占中企研究名额。

## 三、准入评估的最低问题

每个新候选先回答六个问题：

1. 公司靠什么赚钱，客户为什么持续付钱？
2. 所属主线是否足够长期、足够大、足够重要？
3. 公开信息源是否稳定，能否持续跟踪？
4. 财务质量是否有基本可读性，现金流是否能解释？
5. 估值是否能拆解，还是完全靠叙事支撑？
6. 它补的是哪块拼图：行业主线、产业链、竞品对照、真实决策，还是资产配置观察？

如果六个问题答不清，最多进入 C 层或暂不入池。

## 四、升级触发条件

公司可以升级，但必须由事实触发。

| 调整 | 触发条件 |
| --- | --- |
| C → B | 信息源变稳定，业务逻辑能讲清，出现明确验证点 |
| B → A | 关键验证点兑现，财务质量改善，估值可拆解，且能影响真实决策 |
| A 提高优先级 | 护城河增强、现金流改善、估值仍有安全边际，或新事件显著强化主线 |

升级不能只因为股价上涨、市场热度提高或叙事变流行。

## 五、降级触发条件

公司也必须接受降级。

| 调整 | 触发条件 |
| --- | --- |
| A → B | 长期逻辑没有坏，但关键数据连续低于验证要求，估值安全边际下降，或信息源不足以支撑高频跟踪 |
| B → C | 验证点长期没有进展，财务/业务数据无法支撑继续深看 |
| 任意层 → 暂不入池 | 商业模式看不懂、财务质量明显恶化、治理问题、信息披露失真、负债/现金流风险扩大 |

降级不是惩罚，而是节省研究资源，避免系统被旧判断绑架。

## 六、固定复评节奏

| 周期 | 输出 | 完成标准 |
| --- | --- | --- |
| 每周 | 新增 3-10 个候选线索 | 每个候选给出主线、触发原因、初步层级和下一步；中企候选原则上不少于一半 |
| 每月 | A/B 层复评 | 每家公司至少确认一次：维持、提高优先级、降级观察或移出 |
| 每季度 | 研究池升降级报告 | 输出新进 A 层、从 A 层降级、进入暂不入池、下季度重点主题 |

## 八、下一步执行

1. 先把当前 A/B/C 层和复评日期做成门户可读的研究池状态表。
2. 每周新增候选只做初筛，不急着建主页。
3. 每月复评 A/B 层公司，明确是否维持、升级、降级或暂停。
4. 每季度输出一次研究池升降级报告，避免核心池固化。
