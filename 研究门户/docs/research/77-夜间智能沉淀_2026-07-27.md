### NVIDIA：Open Secure AI Alliance 聚合云、安全、企业软件与开源伙伴，NVIDIA 把开放 Agent 安全栈推向行业共建

- 来源：[Industry Leaders Unite in Open Secure AI Alliance for AI Safety and Security](https://blogs.nvidia.com/blog/open-secure-ai-alliance/)
- 日期：2026-07-27
- 事件类型：企业 AI / 开源安全生态 / Agent 运行时
- 优先级：P2

原文宣布成立 Open Secure AI Alliance，建立在 Linux Foundation 的 Akrites initiative 和 OpenSSF 社区工作基础上，目标是用开放技术、模型、harness 和工具帮助 AI 时代的软件与 agent 安全防护、漏洞修复和披露。文章强调防御方需要能在本地检查、适配和运行的开放前沿工具，以降低单点失效并满足主权控制、数据保护和多供应商环境。

核心证据：

- 联盟工作方向包括用开放技术进行漏洞 remediation 与 disclosure。
- 原文以 Hugging Face 安全事件为例：Hugging Face 在自有基础设施上运行开源权重 GLM 5.2，分析超过 17,000 个 actions 并控制入侵。
- 首批参与方覆盖 Microsoft、Cloudflare、CrowdStrike、Databricks、Dell、HPE、Hugging Face、IBM、LangChain、Palantir、Palo Alto Networks、Red Hat、SAP、ServiceNow、Siemens、Snowflake、Synopsys 等云、安全、企业软件和开源生态公司。

业务影响主要在企业 AI 软件生态和 agent 安全治理层。企业要让 agent 进入代码、IT、金融、制造、供应链和安全运维，核心约束包括权限边界、可审计性、本地运行、漏洞修复和多供应商兼容。若联盟能围绕开放模型、harness、runtime 和安全工具形成事实标准，会提高 NVIDIA 在企业 agent 安全执行层的话语权，并让 OpenShell、Nemotron、NemoClaw、CUDA-X skills 等软件栈更容易被企业软件和安全厂商集成。

估值/动作上，这条事件支持 NVIDIA 的平台溢价和软件生态可选项，但权重低于 Blackwell/Rubin 供给、网络产品、云厂资本开支和明确客户部署。本轮不因联盟新闻上调盈利预测或仓位动作，继续把它作为 enterprise agent attach rate、软件生态和安全运行时标准化的观察点。
