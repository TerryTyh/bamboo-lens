## 本轮正式沉淀

### NVIDIA｜Nemotron 3 Ultra 接入 LangChain Deep Agents，NVIDIA 把开源智能体栈推到接近闭源模型的企业可用区间

- 来源：[NVIDIA Nemotron Achieves Benchmark-Leading Performance With LangChain Deep Agents Harness](https://blogs.nvidia.com/blog/nemotron-langchain-agents-open-stack/)
- 事件类型：企业 AI / 智能体软件栈 / 开源模型
- 优先级：P2

原文讲的是 NVIDIA Nemotron 3 Ultra 与 LangChain Deep Agents 的适配结果。LangChain 针对 Nemotron 3 Ultra 调整 Deep Agents harness，在不重新训练模型的情况下，通过系统提示词、工具描述和中间件调优，使其在 Deep Agents benchmark 上取得开源模型最高准确率，并达到与最高分闭源模型相当的业务任务表现。

关键证据：

- 单次推理运行成本比领先闭源模型低 10 倍。
- LangChain 智能体工程平台每月下载量超过 2 亿次。
- 调优后的 profile 已可直接通过 LangChain 使用。
- NVIDIA NemoClaw for LangChain Deep Agents 组合 LangChain Deep Agents Code、Nemotron 3 Ultra 调优结果和 NVIDIA OpenShell 安全运行时。
- Abridge、Amdocs、Box 正在把专用智能体嵌入平台，EY 正在扩展围绕相关蓝图的实施能力。

业务判断：这不是大额订单新闻，也没有披露软件收入或 GPU 采购金额；但它把 NVIDIA 企业智能体路线从模型发布推进到主流编排平台可直接使用的开放栈。若 10 倍成本优势能在真实企业工作流复现，会降低持续评估、多场景部署和私有治理门槛，拉动企业推理、NemoClaw/OpenShell/NIM 与系统集成生态的配套需求。

估值与动作：维持 NVIDIA A 池核心，不因单条软件栈进展追高，也不单独上调估值中枢。后续重点看企业客户数量、NemoClaw/OpenShell/NIM 的收费口径、软件 attach、推理工作负载增长，以及是否在财报中体现为软件和服务收入。
