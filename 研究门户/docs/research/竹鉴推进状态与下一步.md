# 竹鉴推进状态与下一步

更新日期：2026-05-17

这份文档作为竹鉴项目的当前进度锚点。它不替代正式研究资料，只用来回答三件事：我们已经做到哪里、当前正在打磨什么、下一步应该做什么。

## 一、当前阶段

竹鉴已经从“静态研究资料库”进入“动态决策系统 V2”阶段。

当前重点不是继续扩很多公司，而是先把样板闭环打磨稳定，再复制到其他核心公司：

- 阿里巴巴：平台现金流、云 AI、即时零售、回购、港股/中概折价与估值修复。
- 立讯精密：现金流、营运资本、消费电子/汽车电子/通信与数据中心、新业务质量与组合集中度。
- NVIDIA：Data Center 现金流、AI 工厂平台、网络与系统控制点、推理/企业 agent/物理 AI，以及高估值下的验证条件。
- GE Vernova：订单、backlog、Power / Electrification 利润率、自由现金流、Prolec 并表和高估值容错率。
- Constellation Energy：核电稀缺资产、147 million MWh 可签约电量、PPA/长期供电协议、Calpine 整合、EPS 和自由现金流。

## 四、质量底线

后续任何动态、日报、公司主页内容都必须遵守：

1. 不读原文，不形成正式事件。
2. 没有事实、数字和证据，不进入公司主页。
3. 动态详情页先讲原文和事实，再讲分析。
4. 公司主页只展示价值内容，方法论收进规则入口。
5. 公司估值动作只看估值位置和基本面状态；个人组合仓位属于独立资产配置模块，不能用一次对话或单张截图临时写入公司页。

## 五、下一步

下一步继续推进“动态决策系统 V2 闭环”：

1. 阿里、立讯、NVIDIA、GE Vernova、Constellation Energy 已完成第一轮精修。
2. 正式事件到公司主页的质量门槛、回写分流、字段精确写入、去重覆盖、板块预算、可读性审计和审计驱动调参已完成。
3. 下一步做“公司页主线复核”：检查自动沉淀是否真正更新了业务、财务、估值主线，而不是只生成了合格但无增量的卡片。
4. 同时准备首页收敛：把过程类、规则类、系统说明类内容迁移到统一入口，首页继续只保留决策入口。
