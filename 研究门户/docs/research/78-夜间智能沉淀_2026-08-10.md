## 原文事实

NVIDIA 在 2026-08-04 围绕 Future of Memory and Storage 会议发布官方文章，说明 AI 工厂的数据瓶颈正在从 GPU 算力扩展到内存、存储、加密、压缩、校验和数据重构。原文披露 GPU 可以直接发起存储请求并产生数千个并发操作，因此传统 CPU 承担的数据服务可能成为智能体和大规模数据访问的新瓶颈。

关键证据包括：

- NVIDIA 宣布开源 cuFile API 及其底层存储软件栈，让 GPU 而不只是 CPU 直接从存储读写数据；cuFile 属于 GPUDirect Storage 组件。
- NVIDIA 引用 benchmark 称，Vera CPU 在两阶段压缩和加密流水线中的吞吐最高达到 x86 CPU 的 3.21 倍。
- Storage-Next 由 NVIDIA 推动，覆盖超过 40 家存储和闪存厂商，原文点名 DDN、KIOXIA 和 Micron。
- SCADA 框架用于让大规模并行 GPU 只把应用需要的数据从存储直接拉入高速内存，DDN 正在把 SCADA 集成到 Infinia 平台。

## 投资解释

这条事件的业务含义在于，NVIDIA 的 AI 工厂平台控制点继续从 GPU、网络和系统扩展到数据路径与存储标准。若 GPUDirect Storage、cuFile、SCADA、Vera/BlueField 数据服务和 Spectrum-X 网络被存储厂商与云厂商持续采用，NVIDIA 的平台边界会从服务器算力延伸到存储访问、数据服务和 I/O 调度。

估值和动作上，它支持 NVIDIA 的平台溢价和长期 attach rate 想象，但权重低于 Blackwell/Rubin 出货、云厂资本开支、网络收入、软件收入和明确客户部署。原文没有披露采购金额、收入贡献、收费模式或 Data Center 分部量化拉动，因此本轮维持核心跟踪，不上调盈利预测或估值区间。
