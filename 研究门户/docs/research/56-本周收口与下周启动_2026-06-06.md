# 本周收口与下周启动

日期：2026-06-06

这份记录用于给下周一启动留一个明确入口。本周的主要矛盾已经从“能不能跑起来”转成“日报和首页必须展示目标公司新闻，而不是竹鉴自己的操作记录”。

## 一、本周完成

1. 完成 A 股扩池第一轮：长电科技、北方华创、中微公司、中际旭创、新易盛、沪电股份、深南电路、工业富联等进入候选雷达。
2. 完成 ASMPT 一页式观察卡：定位为先进封装设备侧 B 层候选，不直接触发组合动作。
3. 完成北方华创一页式观察卡：补前道半导体设备国产化样本，等待 2026H1/Q2 数据验证收入、毛利率和现金流。
4. 完成中微公司一页式观察卡：与北方华创形成设备侧对照，重点看刻蚀、MOCVD、新产品和研发效率。
5. 完成中际旭创与新易盛光模块正式对照卡：两者都进入 B 层对照观察，中际旭创略优先，新易盛保留高弹性备选。
6. 完成长电科技强 B 复核：维持强 B，不升 A；下一次只看 2026H1/Q2 毛利率、长电微、经营现金流和 capex 回报。
7. 修复日报发送门槛：企业微信不再发送“今日待读候选”“已抓到原文链接但未摘要”“今日没有新的可读内容”这类半成品。
8. 触发并验证云端 Daily Brief：最新验证结果是无合格公司动态时会跳过发送，不再把候选标题伪装成日报。

## 二、本周遗留风险

1. 日报内容质量已经加门槛，但下周一仍要验证真实定时任务是否按新规则运行。
2. 候选草稿数量变多，尤其是 A 股投资者关系活动记录表，容易把标题列表误当成公司新闻。
3. 首页“最近更新”和组合总览已开始合并正式事件与外部候选，但候选必须有原文摘要；否则只能留在候选研判台。
4. 外资公司仍有正式事件存量优势，首页展示需要继续保持中企/外资均衡。
